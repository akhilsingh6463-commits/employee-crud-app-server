# employee-crud-app-server

1. Install dependencies:
   ```bash
   npm install
   ```

2. Create `.env` file from `.env.example`:
   ```env
   PORT=5000
   DB_HOST=localhost
   DB_USER=root
   DB_PASSWORD=your_mysql_password
   DB_NAME=crudapp
   ```

3. Start the server:
   ```bash
   npm run dev
   ```

Server will run on [http://localhost:5000](http://localhost:5000).
